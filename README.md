# Project Name

Fidelity Leap Project - used to keep in step with students on project

## Features

- Java based project with Angular and Kafka


## Prerequisites

Before you begin, make sure you have installed:

- Java 25 (or your version)
- Maven 3.9+
- Git

## Installation

Clone the repository:

```bash
git clone https://github.com/bhickey777/FidelityLeapProject.git
cd FidelityLeapProject
```

Build the project:

```bash
mvn clean install
```

## Running the Application

Run using Maven:

```bash
mvn spring-boot:run
```

Or run the generated JAR:

```bash
java -jar target/FidelityLeapProject.jar
```

## Running Tests

```bash
mvn test
```
